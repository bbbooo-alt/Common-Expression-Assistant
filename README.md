# 快捷键输入工具

一个 Windows 平台的快捷键输入工具，允许用户设置自定义快捷键来快速输入常用文本内容。

## 功能特性

- **自定义快捷键**：支持设置 Ctrl、Alt、Shift 等组合键
- **名称管理**：为每个快捷键设置易于识别的名称
- **内容管理**：存储要粘贴的完整文本内容
- **启用/禁用**：灵活控制每个快捷键的启用状态
- **搜索过滤**：快速查找快捷键
- **详情查看**：查看完整的文本内容
- **现代化 UI**：简洁美观的界面设计

## 数据结构

每个快捷键包含以下字段：
- `快捷键`：如 `ctrl+1`、`alt+f1` 等
- `名称`：快捷键的标识名称（未填写自动生成"未命名1"）
- `内容`：实际要粘贴的文本
- `enabled`：是否启用

## 使用方法

### 1. 安装依赖
```bash
pip install pywin32
```

### 2. 运行程序
```bash
python hotkey_typer.py
```

或使用启动脚本：
```bash
启动工具.bat
```

### 3. 添加快捷键
1. 点击"+ 添加快捷键"按钮
2. 输入快捷键（如 `ctrl+1`）
3. 输入名称（可选，留空自动生成）
4. 输入要粘贴的内容
5. 点击保存

### 4. 使用快捷键
1. 开启"监听状态"开关
2. 在任意输入框中按下设置的快捷键
3. 程序会自动输入对应的内容

## 界面说明

### 统计卡片
- 快捷键总数
- 启用数量
- 今日使用次数

### 列表项
- **快捷键**：蓝色标签显示
- **名称**：快捷键的标识
- **状态**：启用/禁用开关
- **操作**：修改、删除、详情按钮

### 详情弹窗
点击"详情"按钮可查看完整的文本内容。

## 文件说明

- `hotkey_typer.py`：主程序文件
- `hotkey_config.json`：配置文件（自动创建）
- `启动工具.bat`：快速启动脚本
- `install_requirements.bat`：依赖安装脚本

## 系统要求

- Windows 操作系统
- Python 3.6+
- pywin32 库

## 注意事项

1. 快捷键需要包含 `+` 符号，如 `ctrl+a`、`alt+1`
2. 程序需要管理员权限才能监听全局快捷键
3. 配置文件 `hotkey_config.json` 会自动保存在程序目录
